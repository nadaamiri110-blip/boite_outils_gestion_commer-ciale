# Boîte à outils de gestion commerciale

## Description
Ce projet regroupe quatre petits programmes Python destinés à effectuer des calculs de gestion commerciale.

## Fichiers
- `marge.py` : calcule la marge commerciale, le taux de marge et le taux de marque.
- `tva.py` : calcule le montant de la TVA et le montant TTC.
- `interets.py` : calcule les intérêts simples et le montant final.
- `total_ventes.py` : calcule le total et la moyenne des ventes à partir de `ventes.csv`.
- `ventes.csv` : contient les données de ventes utilisées par le programme.

## Exécution
Ouvrir un terminal dans le dossier du projet puis lancer, par exemple :

```bash
python marge.py
python tva.py
python interets.py
python total_ventes.py
```

## Prérequis
- Python 3 installé.
- Aucun module externe n'est nécessaire.
